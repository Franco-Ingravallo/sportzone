# ⚡ SportZone Talca

Aplicación web SPA desarrollada con React + Vite para la evaluación EV1-web del curso **Electivo III – Programación de Aplicaciones Web** (ICI, UCM).

## 🚀 Deploy
🔗 [Ver aplicación en Vercel](https://sportzone-red.vercel.app/)

## 🛠️ Tecnologías
- React + Vite
- react-router-dom (createBrowserRouter)
- CSS Modules
- Google Fonts (Oswald + Roboto)
- GitHub + Vercel

## 📄 Páginas
- **Home** – Hero animado, propuesta de valor y beneficios
- **Productos** – Catálogo con cards generadas desde dummy.js
- **Equipo** – Presentación del equipo de la tienda
- **Developer** – Información del desarrollador
- **404** – Página de error para rutas no encontradas

## 📦 Instalación local
```bash
git clone https://github.com/Franco-Ingravallo/sportzone.git
cd sportzone
npm install
npm run dev
```
